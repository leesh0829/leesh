## 1. junome.info — 개인 멀티기능 사이트

Junha Park(iOS 개발자)의 개인 사이트. 상단 고정 내비: **Home · Daily · Docs · Blog · Works**. 다크 테마 + 클린 산세리프 + 한/영 병기 + 넉넉한 여백 + 카드/그리드. 이 사이트는 "블로그+문서+미디어기록+포트폴리오"를 한 셸에 담은 구조라 Leesh와 직접 대응된다.

### 1-1. 공통 셸 / 전역 기능
- **⌘K 커맨드 팔레트** — Docs·Daily 헤더에 `⌘K` 검색. 페이지/글 빠른 점프 + 콘텐츠 검색.
- 상단 고정 헤더 + 소셜 링크 푸터.

### 1-2. `/portfolio` (포트폴리오)
- **모듈형 카드 레이아웃**: 히어로(이름+태그라인) → 대표작 → About → 프로젝트 17개 → 여정 타임라인 → 기술스택 → 푸터.
- **프로젝트 카드**: 아이콘 + 메타 태그(`[PROJECT]` `[LIBRARY]` `[TOY]`)로 유형 구분.
- **여정 타임라인**(2021–2024): 날짜별 커리어 항목.
- **기술스택**: 태그 리스트로 나열.
- **큐레이션 컬렉션**: 음악 30곡, 영화/책 리뷰(썸네일 갤러리).
- 하위: `/portfolio/works` `/portfolio/music` `/portfolio/about` `/portfolio/journey`.

### 1-3. `/docs` (문서 사이트)
- **좌측 사이드바 트리**: 프로젝트 카테고리 접기/펼치기, "모두 펼치기" 액션.
- **브레드크럼**: `Docs > PerfectContributionsView`.
- **배지 시스템**: 호환성 표시(SPM/CocoaPods/Carthage 등).
- **코드 블록**: 문법 강조 + 설치 탭(패키지 매니저 3종 전환).
- **문서 상세 구성**: Overview → Installation → Setup → Examples → Customization → Author → License.
- **`/docs/changelog`**: 월(月) 단위 그룹 + 역순 + **NEW 태그** + 우측 TOC.
- 카테고리별 프로젝트 문서 다수(`/docs/projects/...`).

### 1-4. `/daily` (미디어 기록/일상 아카이브)
- **카테고리 필터 칩 + 개수**: `영화(53)` `애니(5)` `일상(1)` `뮤지컬(1)` `만화(2)` `회고(1)` `책(4)` — 칩에 **건수 배지**.
- **미디어 카드 그리드**(마소너리형): 썸네일 + 유형 배지 + **별점(★ 0.9–5.0)** + 제목/부제 + 날짜.
- **⌘K 검색**.
- 역순 정렬, 총 67개 항목. 태그라인 존재.

### 1-5. 콘텐츠 상세 페이지(리스트→상세 UX)
`/daily/michael`, `/blog/...` 공통 패턴:
- **히어로 이미지**(포스터/썸네일)로 시각적 정체성.
- **메타 바**: 제목 + 별점 + 날짜 + 카테고리 태그 + 부가정보(감독/러닝타임/관람등급/장소 등).
- **한 줄 요약(one-liner)** 을 본문 앞 감정 앵커로.
- **읽기 메타**: 블로그 글엔 **읽는 시간("12-minute read")** + **난이도("Advanced")**.
- **목차(TOC)**: 앵커된 섹션 헤더로 페이지 내 이동.
- **이전/다음 글** 링크(양옆).
- **관련글 "이어서 읽을 기록"**: 썸네일+날짜+카테고리 카드 3~4개.
- **댓글**: GitHub 로그인 기반.
- **아카이브로 돌아가기** 푸터 링크.

## 2. ciechanow.ski — 인터랙티브 기술 설명

물리/공학/그래픽스를 **스크롤 연동 인터랙티브 시각화(WebGL/캔버스)** 로 설명하는 개인 블로그. `/archives`는 연도별 그룹의 심플한 인덱스(날짜+제목 링크). 강점은 인덱스가 아니라 **각 글의 손수 만든 인터랙티브 위젯**.

- **참고 포인트**: "설명을 글로만 하지 않고 만져보게 한다"는 철학.
- **현실 판단**: 글마다 커스텀 WebGL을 만드는 **초고비용** 방식. Leesh에 통째 적용은 비현실적. 다만 투자/가계부 통계의 **작은 인터랙티브 차트** 정도로는 영감 차용 가능.

### 제외/보류 사유
- **별점 + 미디어 유형 배지**(daily): Leesh 일기는 "비공개 마크다운 메모"라 성격이 다름 → 별도 미디어리뷰 기능을 새로 만들 게 아니면 부적합.
- **GitHub 로그인 댓글**: Leesh는 자체 NextAuth/게시판 댓글 보유 → 불필요.
- **G(인터랙티브 위젯)**: 투자 대비 효과 낮음. 통계 화면 개선 시 부분 차용만.
